# User Guide for InterviewPro

This guide will help you navigate and make the most of your InterviewPro experience, whether you're a candidate taking an interview or an interviewer reviewing candidates.

## For Candidates (Interviewees)

### Getting Started

1. **Access the Platform**

   - Navigate to the InterviewPro website
   - Click on the "Start Interview" button on the landing page

2. **Resume Upload**

   - Upload your resume in PDF or DOCX format
   - The system will automatically extract key information
   - File size limit: 10MB

3. **Verify Your Information**
   - Review the extracted information for accuracy
   - Make any necessary corrections
   - This information will be used to personalize your interview

### Taking the Interview

1. **Understand the Format**

   - The interview consists of multiple-choice technical questions
   - Questions are tailored to your skills and experience
   - Each question has a time limit based on its difficulty

2. **Answer Questions**

   - Read each question carefully
   - Select the best answer from the options provided
   - Submit your answer before the timer runs out
   - You can navigate between questions if needed

3. **Complete the Interview**
   - After answering all questions, review your answers
   - Submit the interview for evaluation
   - Your interview will be automatically scored

### Viewing Results

1. **Score Overview**

   - See your overall score and performance metrics
   - Review question-by-question breakdown
   - Read AI-generated feedback on your performance

2. **Detailed Analysis**

   - Each question shows:
     - Your answer
     - The correct answer (if different)
     - Explanation of the correct approach
     - Score for that question

3. **Tracking Progress**
   - Access your interview history from the dashboard
   - Compare results across multiple attempts
   - See improvement trends over time

### Tips for Success

- **Prepare Your Resume**: Ensure your resume accurately reflects your skills and experience
- **Technical Environment**: Use a stable internet connection and modern browser
- **Read Carefully**: Take time to understand each question before answering
- **Use All Available Time**: Don't rush through questions unnecessarily
- **Review Your Work**: Check your answers before final submission
- **Learn from Feedback**: Use the detailed analysis to improve for future interviews

## For Interviewers

### Dashboard Navigation

1. **Accessing the Dashboard**

   - Navigate to the interviewer portal
   - Sign in with your credentials
   - You'll see the main interviewer dashboard

2. **Understanding the Interface**
   - Top section: Key statistics and metrics
   - Tabs: Filter candidates by status
   - Search bar: Find specific candidates
   - Table: Detailed candidate list

### Managing Candidates

1. **Viewing Candidates**

   - All candidates are listed in the main table
   - See key information at a glance:
     - Name and contact details
     - Interview score
     - Status
     - Date completed

2. **Filtering and Sorting**

   - Use the search bar to find candidates by name or email
   - Click column headers to sort by that attribute
   - Use the tabs to filter by interview status

3. **Viewing Detailed Results**

   - Click on any candidate row to view detailed information
   - The detail view shows:
     - Personal information
     - Resume highlights
     - Question-by-question breakdown
     - Overall score and analysis

4. **Multiple Attempt Tracking**
   - See all interview attempts by the same candidate
   - Compare scores across attempts
   - Track improvement over time

### Analyzing Performance

1. **Understanding Scores**

   - Overall score represents technical proficiency
   - Question breakdown shows strengths and weaknesses
   - AI-generated summaries provide additional context

2. **Comparing Candidates**

   - Sort by score to rank candidates
   - Use filters to create shortlists
   - View detailed reports to make informed decisions

3. **Using the Summary**
   - Each interview includes an AI-generated summary
   - The summary highlights key strengths and weaknesses
   - Use this for quick candidate evaluation

### Best Practices

- **Regular Review**: Check the dashboard frequently for new completed interviews
- **Detailed Analysis**: Look beyond the overall score to question-level performance
- **Multiple Attempts**: Consider improvement trends when evaluating candidates
- **Consistent Criteria**: Use the same evaluation standards across candidates
- **Feedback Integration**: Consider the AI analysis alongside your own evaluation

## Troubleshooting

### Common Issues for Candidates

1. **Resume Upload Problems**

   - Ensure file is in PDF or DOCX format
   - Check that file size is under 10MB
   - Try converting the file if issues persist

2. **Information Extraction Issues**

   - If information is incorrectly extracted, manually correct it
   - Use clear, standard formatting in your resume for better extraction

3. **Technical Problems During Interview**
   - If your connection is lost, the system will save your progress
   - Return to the interview to continue where you left off
   - If timer issues occur, contact support with your session ID

### Common Issues for Interviewers

1. **Dashboard Loading Issues**

   - Try refreshing the page
   - Clear browser cache and cookies
   - Ensure you have proper permissions

2. **Missing Candidate Data**

   - Verify the candidate has completed their interview
   - Check search filters that might be hiding candidates
   - Contact support if data appears to be missing

3. **Report Generation Problems**
   - Try using a different browser
   - Ensure you have proper permissions
   - Contact support if issues persist
